Mirlward

A verifiable, offline tool for Bitcoin seed phrases and keys. One HTML file that lets you prove the tool has not been tampered with, and prove your backup restores the right wallet before you rely on it.

Open source · Apache-2.0 · current release v0.1.0-beta (pre-release)

Mirlward is a separate project by the same author. It uses strictly standard Bitcoin cryptography (BIP39, BIP32, BIP44, BIP84, BIP173) and adds nothing of its own: the point is that every output can be checked.

What it does

  • Verify the tool. A single self-contained file with a published SHA-256 pin, a reproducible build and a conformance corpus of official test vectors.
  • Verify the backup. Enter a phrase; Mirlward checks the checksum and shows the key fingerprint, account xpubs and first addresses, so you can compare them with a known wallet before trusting the paper.
  • Stay offline. No network requests, no accounts, no telemetry, nothing stored. Reloading the page wipes memory.

Download

Get mirlward_beta.html and its .sha256 file from the v0.1.0-beta release on GitHub. SHA-256 of mirlward_beta.html:

55cb0b107bf19165a881b041316c8a124245efb2619778474db91d070065ddc2

Verify your copy

shasum -a 256 mirlward_beta.html               # macOS
sha256sum mirlward_beta.html                   # Linux
certutil -hashfile mirlward_beta.html SHA256   # Windows

If the result differs from the pin above, do not use the file. To check correctness against the official vectors, with no dependencies:

node conformance.js

Use it safely

Your seed phrase is the master key to your money. Anyone who sees it controls the coins; if you lose it, there is no recovery.

  1. Save the file to a USB stick.
  2. Open it on an air-gapped machine, ideally booted from a clean live USB.
  3. Write the phrase on paper, in order. Never a photo or a cloud note.
  4. Close the page and secure the machine.

Before using it with real funds, read the threat model.
